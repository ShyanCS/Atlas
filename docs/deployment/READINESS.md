# Public source readiness

The repository contains the React/TypeScript Dispatch Canvas, Django API/domain engine, normalized provider adapters, tests, API schema and prepared free-host configuration.

Local verification before publication: 273 PostgreSQL backend cases, 271 SQLite cases (two PostgreSQL-only skips), 42 frontend cases and 23 browser checks passed. These are local results; the CI badge reports actual GitHub execution separately.

The risk policy remains `atlas-assessment-policy-v1.0.0`. Wind, rain/snow endpoint conventions, strict cargo overrides, maximum severity, Unknown/No Travel eligibility, midpoint exposure and lexicographic ranking remain backend-authoritative.

Public live-provider access is not enabled by publishing source. Open-Meteo is limited to the approved personal noncommercial assessment scope, with disclosed provider snowfall approximation and unavailable model-run metadata. Both public release confirmation flags default to zero.

The preferred hosting configuration is Cloudflare Pages Free, Render Free and Neon Free. No hosted application is claimed here. Follow [setup](SETUP.md), verify actual accounts/limits and obtain separate deployment authorization.

Historical research, original employer files, design packages, private provider data, databases, environments and release archives are preserved locally but omitted from public source. Only authored sample screenshots are included.
